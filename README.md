# veyww

Музыкальный плеер для Windows, Android и браузера. Доступны «Моя частота», плейлисты, настройки звука, темы, мини-плеер Windows и офлайн-медиатека.

## Download

- **Windows** — [скачать установщик veyww 0.20.6 beta](https://github.com/veywrr/veyww/releases/download/v0.20.6/veyww-Windows-0.20.6-Setup.exe).
- **Android** — [скачать APK 0.20.6](https://github.com/veywrr/veyww/releases/download/v0.20.6/veyww-Android-0.20.6-beta.apk) или открой [@veyww_bot](https://t.me/veyww_bot). Установи поверх прежней версии, чтобы сохранить данные.
- **Браузер** — [открыть veyww.space](https://veyww.space/).

Сайт и нативные клиенты проверены отдельно. Android прошёл пять проверок на эмуляторе Android 14, включая офлайн-запуск и эффекты без сети.

Задержки и отказы на стороне внешнего источника всё ещё возможны; этот выпуск не гарантирует доступность каждой записи SoundCloud.

## Запуск публичного снимка исходников

Публичный снимок исходников может отличаться от актуальных установщиков. Инструкции ниже относятся к этому снимку.

Нужны Node.js 22.13 или новее и Python 3.10 или новее. Python нужен для поиска и подключения к поддерживаемым музыкальным источникам. Для запуска плеера с локальными файлами он не требуется.

```sh
npm ci
npm run prepare:web
python -m pip install yt-dlp certifi
npm run preview
```

Откройте `http://127.0.0.1:8765`. На Windows после подготовки интерфейса можно запустить приложение командой `npm start`.

Локальный экземпляр Windows и веб-версии создаёт свою базу и аккаунты. Данные с veyww.space в него не переносятся. Доступность треков зависит от источника. Аудиофайлы в комплект не входят.

## Android

Установите JDK 17, Android SDK 35, SDK Build Tools 35.0.0, Gradle 8.9 и Python 3.12. Выполните `npm run prepare:web` из корня, затем запустите `gradle :app:assembleDebug` из папки `android`.

Сборка использует локальную отладочную подпись и устанавливается отдельно от официальной беты. Онлайн-интерфейс подключается к veyww.space. Сохранённые треки можно открыть из локального раздела «Офлайн».

Проверки: `npm test` и `python -m unittest discover -s provider -p "test_import.py"`.

## Зависимости

HLS.js распространяется по Apache-2.0, SoundTouchJS AudioWorklet по MPL-2.0. `npm run prepare:web` добавляет их файлы лицензий вместе с браузерными модулями.
